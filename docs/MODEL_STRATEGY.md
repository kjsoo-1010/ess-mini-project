## 모델 설계 전략

**예측 목적.** 배터리 셀 1개의 초기 100 사이클 측정값으로, 그 셀이 EOL(0.88 Ah)에 도달할 때까지의 총 사이클 수를 예측한다. Batch 1로 학습하고 Batch 2로 평가한다.

### 0. EDA에서 전략으로

| EDA 질문 | 발견 | 시사점 | 전략 반영 |
|---|---|---|---|
| 1. 수명 분포 | 세 배치 모두 오른쪽으로 긴 꼬리. Batch 2는 77%가 Batch 1의 최솟값(534)보다 짧음 | 학습 범위 밖을 예측해야 함 | target 로그 변환, 범위 밖 예측이 가능한 선형 계열 모델 |
| 2. 열화 곡선 | 평탄 구간 뒤 급락. knee는 수명의 82 ~ 87% 지점이며 초기 100 사이클에는 나타나지 않음 | 초기 용량 값으로는 수명을 구분할 수 없음 | 용량 수준(QD)은 주 피처에서 제외 |
| 3. ΔQ(V) | log 분산과 log 수명의 상관이 -0.94 / -0.92 / -0.80 | 초기 100 사이클에서 수명을 구분하는 신호 | ΔQ(V) 분산을 핵심 피처로 사용 |
| 4. 충전 조건 | Batch 1에서는 충전 시간이 강한 변수(0.79). Batch 2·3은 충전 시간이 약 10분으로 일정 | 배치가 바뀌면 관계가 유지되지 않음 | 정책명은 사용하지 않음. 충전 시간은 보조 후보로만 검토 |
| 5. 상관관계 | 배치 간에 부호가 유지되는 것은 ΔQ(V) 계열뿐. ΔQ 통계값끼리 0.93 ~ 0.99 상관 | 피처가 서로 중복됨, 학습 셀은 41개 | 피처 수를 적게, 규제 선형 모델 |

### 1. Feature Engineering

피처는 세 가지 기준으로 고른다. 초기 100 사이클 안에서 계산할 수 있을 것, 배치가 바뀌어도 수명과의 관계가 유지될 것, 단일 사이클의 측정 이상값에 흔들리지 않을 것.

| 구분 | 피처 | 계산 | 근거 |
|---|---|---|---|
| 핵심 | ΔQ(V) 분산 (로그) | log10 var(Q100(V) − Q10(V)) | 세 배치 모두에서 수명과 강한 음의 상관 (-0.94 / -0.92 / -0.80) |
| 보조 후보 | 초기 용량 변화 | cycle 100 용량 − cycle 2 용량 | 최단 수명 셀은 100 사이클 안에 이미 용량이 감소 |
| 보조 후보 | 충전 시간 | 초기 100 사이클의 중앙값 | Batch 1에서 0.79. 단, Batch 2·3에서는 값이 일정해 효과를 검증한 뒤 채택 |
| 보조 후보 | 평균 온도, 내부저항 변화 | 초기 100 사이클의 평균, cycle 100 − cycle 2 | Batch 1에서 약한 상관. 배치 간 부호가 일정하지 않아 검증 후 채택 |
| 제외 | 충전 정책명 | - | 배치 간에 거의 겹치지 않고, 같은 정책도 배치에 따라 수명이 다름 |
| 제외 | ΔQ(V) 최솟값·평균 | - | 분산과 사실상 같은 정보 (-0.95, -0.93) |
| 제외 | 용량의 절대 수준 | - | 배치마다 수준이 달라(1.06 ~ 1.09 Ah) 배치 차이가 그대로 들어감 |
| 제외 | cycle 100 이후의 값, knee point | - | 입력 범위를 벗어남 (누수) |

보조 후보는 Batch 1 내부 검증에서 핵심 피처 하나만 쓴 모델보다 나아질 때만 채택한다.

### 2. Regression vs Classification

처음에는 Classification을 목표로 검토했다. 제조 직후 단수명 셀을 빠르게 걸러내는 것이 현장에서 가장 직접적인 활용이기 때문이다. 그러나 이 데이터에서는 분류 모델을 직접 학습할 수 없어, **Regression을 선택하고 그 모델로 분류 문제를 우회해서 푼다.**

| | Regression | Classification |
|---|---|---|
| Target | log10(cycle_life) | cycle_life ≥ 550이면 1 |
| 입력 범위 | 초기 100 사이클 | 초기 5 사이클 |
| 평가 지표 | MAPE (%) (원래 단위로 되돌려 계산) | F1-Score, Accuracy |

Classification을 직접 학습할 수 없는 이유는 두 가지다.

- **학습 데이터에 단수명 셀이 없다.** 550 사이클 미만인 셀이 Batch 1에 1개(41개 중), Batch 2에 30개(39개 중)다. 단수명 클래스를 학습할 수 없고, 내부 검증에서 F1을 계산할 수도 없다.
- **초기 5 사이클에는 수명 신호가 없다.** cycle 2 대비 ΔQ(V) 분산과 수명의 상관을 사이클 수별로 구하면 아래와 같다. 50 사이클부터 신호가 생기고 100 사이클에서 뚜렷해진다.

| 사용한 사이클 | 5 | 30 | 50 | 70 | 100 |
|---|---|---|---|---|---|
| Batch 1 상관계수 | 0.10 | -0.49 | -0.80 | -0.85 | -0.94 |

Regression은 "ΔQ(V) 분산이 클수록 수명이 짧다"는 연속적인 관계를 학습하므로, 학습 데이터에 없는 짧은 수명도 예측값으로 낼 수 있다. target에 로그를 취하는 이유는 수명 분포가 오른쪽으로 치우쳐 있고(왜도 2.14), 로그-로그에서 ΔQ(V) 분산과 직선 관계가 되기 때문이다.

**우회 방법 : Regression 모델로 단수명 셀 선별.** 처음 목표였던 분류 문제는 포기하지 않고, 단수명 예시 없이도 풀 수 있는 형태로 바꿔서 시도한다.

| 막히는 지점 | 접근 |
|---|---|
| 학습 데이터에 단수명 셀이 없음 | 0/1을 직접 학습하지 않는다. Regression 모델의 예측 수명이 550 사이클 미만이면 단수명으로 판정한다 |
| 초기 5 사이클에 신호가 없음 | 입력을 초기 100 사이클로 늘린다. 가이드의 Classification 조건(초기 5 사이클)과 다르다는 점을 결과에 명시한다 |
| 배치가 바뀌면 판정 기준선이 어긋날 수 있음 | Accuracy, F1과 함께 순위 기반 지표(AUC)를 본다. 예측 수명이 짧은 순으로 세웠을 때 실제 단수명 셀이 앞에 오는지를 평가한다 |

성능 리포팅의 주 지표는 MAPE이며, 분류 결과는 별도 표로 보고한다. 입력 조건이 원논문의 분류 실험(초기 5 사이클, 정확도 95.1%)과 다르므로 그 수치와 직접 비교하지 않는다.

### 3. Modeling Strategy

**데이터 처리**

| 항목 | 처리 |
|---|---|
| 학습 / 평가 | Batch 1을 학습 데이터셋으로, Batch 2를 테스트 데이터셋으로 사용한다. Batch 3는 추가 평가에 사용한다 |
| 분할 단위 | 셀 단위. 한 셀의 사이클이 학습과 검증에 나뉘지 않게 한다 |
| 검증 셀 구성 | 수명이 긴 5개 셀이 한쪽에 몰리지 않게 수명 구간을 고려해 나눈다 |
| 품질 처리 | 수명을 알 수 없는 셀 제외, Batch 1의 cycle 1 제외, 불가능한 값(용량 1.3 Ah 초과, 내부저항 0) 결측 처리. 세 배치에 같은 규칙을 적용한다 |
| 변환 | target과 ΔQ(V) 분산에 로그. 스케일링은 학습 데이터에서만 기준을 구해 검증·테스트에 적용한다 |
| 이상값 대응 | 단일 사이클 값 대신 구간 통계(중앙값)를 쓴다. 여러 셀이 동시에 튀는 구간(Batch 1의 cycle 12 ~ 13, Batch 2의 cycle 46 ~ 48, 68 ~ 75)의 값은 피처 계산에 쓰지 않는다 |
| 테스트 데이터 | 피처·모델을 확정한 뒤 한 번만 평가한다. Batch 2 성능을 보고 모델을 다시 고르지 않는다 |

**후보 모델**

| 후보 | 구성 | 선정 이유 (알고리즘 관점) | 선정 이유 (데이터 관점) |
|---|---|---|---|
| 1. 단일 피처 선형 회귀 (기준 모델) | log ΔQ(V) 분산 1개 | 가장 단순하고 해석이 쉬움. 학습 범위 밖으로 직선을 연장해 예측 가능 | 로그-로그에서 직선 관계(-0.94). 원논문도 같은 구성의 모델을 사용 |
| 2. 규제 선형 회귀 (Ridge, Elastic Net) | 핵심 + 보조 후보 피처 | 규제로 계수를 안정시키고, Elastic Net은 불필요한 피처를 걸러냄 | 피처 간 상관이 높고 학습 셀이 41개뿐. 원논문도 Elastic Net 사용 |
| 3. 트리 기반 (Random Forest, Gradient Boosting) | 2와 같은 피처 | 비선형 관계와 피처 간 상호작용을 반영 | 비교용. 학습 범위 밖의 값을 예측하지 못해 Batch 2에서 불리할 것으로 예상 |

딥러닝 등 더 복잡한 모델은 후보에서 뺀다. 학습 셀이 41개뿐이어서 과적합 위험이 크고, 핵심 피처 하나로 이미 강한 선형 관계가 확인되기 때문이다.

**예상 위험과 대응**

| 위험 | 근거 | 대응 |
|---|---|---|
| 학습 범위 밖 예측 | Batch 2의 77%가 Batch 1 최솟값(534)보다 짧음 | 선형 계열을 주 후보로. 트리 계열과의 차이를 비교해 보고 |
| 배치 간 차이 | Batch 2는 같은 ΔQ(V) 분산에서 수명이 더 짧은 쪽에 분포. 같은 정책도 배치에 따라 수명이 다름 | 배치에 민감한 피처(충전 시간, 용량 수준)를 줄임. Gap(Valid−Test)으로 크기를 보고하고 원인을 해석 |
| 과적합 | 학습 셀 41개, 피처 간 상관 0.9 이상 | 피처 수 최소화, 규제, 기준 모델 대비 개선이 있을 때만 피처 추가 |
| 소수 장수 셀의 영향 | 수명 1434 ~ 2237인 5개 셀이 분포에서 떨어져 있음 | 로그 변환, 잔차 분석으로 영향 확인 |
| 원논문 수치와의 비교 | 원논문의 테스트 배치(2017-06-30)는 이 데이터셋에 없음. Batch 2(2018-02-20)는 원논문에 없는 배치 | Gap(Target−Test) 해석 시 평가 조건이 다르다는 점을 명시 |
