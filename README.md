# ESS 배터리 수명 예측

배터리 셀의 **초기 100 사이클 측정값만으로** 그 셀의 총수명(cycle life)을 예측한다. ESS 에서 배터리 교체 비용은 설비 투자의 30 ~ 40%를 차지한다. 수명을 미리 알면 교체 시점을 계획하고, 수명이 짧을 셀을 일찍 가려낼 수 있다.

## 프로젝트 개요

- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12)
- 평가 데이터 : Batch 2 (2018-02-20). 추가 평가로 Batch 3 (2018-04-12)
- 태스크 : **Regression** (Cycle Life 예측)

**Regression 을 선택한 이유.**

- 과제의 배경이 ESS 운영(수명 관리, 교체 계획)이다. 교체 시점을 정하려면 장·단수명 구분이 아니라 수명 값이 필요하다.
- Classification(550 사이클 기준)은 이 데이터로 학습할 수 없다. 학습 배치의 단수명 셀이 41개 중 1개뿐이다.
- 원논문도 회귀가 주된 결과이고, 분류는 선별·등급 분류를 위한 확장으로 다룬다.

분류 관점의 결과는 [추가 결과](#추가-결과--단수명-셀-선별)에 따로 정리했다.

**데이터 구성.**

| 구분 | 파일 | 원본 셀 수 | 사용 셀 수 | 수명 범위 | 용도 |
|---|---|---|---|---|---|
| Batch 1 | 2017-05-12 | 46 | 41 | 534 ~ 2237 | 학습 |
| Batch 2 | 2018-02-20 | 47 | 39 | 392 ~ 1186 | 테스트 |
| Batch 3 | 2018-04-12 | 46 | 40 | 541 ~ 1935 | 추가 테스트 |

Batch 1 과 3 은 원논문의 배치와 같다. **Batch 2 는 원논문에 없는 배치다.** 원논문의 두 번째 배치(2017-06-30)는 이 데이터셋에 들어 있지 않다. 그래서 원논문의 성능 수치와 직접 비교할 수 있는 것은 Batch 3 뿐이다.

## EDA

전처리와 EDA 의 전체 내용은 [DAY 1 보고서](docs/DAY-1.pdf)에 있다. 여기에는 모델 설계로 이어진 발견만 적는다.

**전처리.** 수명을 알 수 없는 셀을 제외했다 (Batch 1 5개, Batch 2 8개, Batch 3 6개). Batch 1 의 5개 셀은 원논문 공식 코드에 따라 수명을 보정했고, 측정값이 없는 cycle 1 과 물리적으로 불가능한 값(용량 1.3 Ah 초과, 내부저항 0)은 제거했다. 수명 종료(EOL)는 공칭 용량 1.1 Ah 의 80%인 0.88 Ah 다.

- Cycle Life 분포
  - 수명 중앙값이 Batch 1 842, Batch 2 472, Batch 3 964.5로 배치마다 다르다. 세 배치 모두 오른쪽으로 긴 꼬리를 가진다.
  - 단수명(<500) 비율은 0% / 72% / 0%, 장수명(>1,000) 비율은 24% / 8% / 48%다.
  - 핵심 발견 : **학습 배치와 테스트 배치의 수명 분포가 거의 겹치지 않는다.** Batch 2 셀의 77%가 Batch 1 의 최솟값(534)보다 짧다.

- 열화 곡선 분석
  - 용량은 오랫동안 평탄하다가 말기에 급락한다. 수명 전반부 50% 동안의 감소는 전체의 3 ~ 10%뿐이다.
  - Knee point 는 세 배치 모두 수명의 82 ~ 87% 지점에서 나타나고, 수명과의 상관계수가 0.986이다.
  - 핵심 발견 : **수명은 knee 가 언제 시작되느냐로 결정되는데, 초기 100 사이클의 용량 곡선에는 그 신호가 없다.**

- ΔQ(V) 곡선 분석
  - ΔQ(V) = Q100(V) − Q10(V). cycle 100 과 cycle 10 의 방전 용량-전압 곡선의 차이다.
  - 단수명 셀은 곡선이 깊게 내려가고(최솟값 중앙값 -0.056 Ah), 장수명 셀은 0 근처에 머문다(-0.022 Ah).
  - 핵심 발견 : **log(ΔQ 분산)과 log(수명)의 상관계수가 Batch 1 -0.94, Batch 2 -0.92, Batch 3 -0.80이다.** 용량 값으로는 구분되지 않던 셀이 전압 곡선의 변화로는 구분된다.

- 충전 속도(C-rate)와 수명의 관계
  - Batch 1 은 충전이 빠를수록 수명이 짧다 (충전 시간과 수명의 상관 0.79).
  - Batch 2 와 3 은 모든 정책의 충전 시간이 약 10분으로 같은데, 수명은 392 ~ 1935로 크게 다르다.
  - 핵심 발견 : **충전 조건은 한 배치 안에서만 수명을 설명한다.** 같은 정책(`6C(60%)-3C`)의 수명이 Batch 1 에서 731, 757이고 Batch 2 에서 392, 408이다.

- 상관관계와 다중공선성
  - 충전 시간, 온도, 내부저항은 배치마다 수명과의 상관 부호가 바뀐다 (충전 시간 : 0.81 / -0.94 / 0.55).
  - ΔQ(V) 의 분산, 최솟값, 평균은 서로 0.93 ~ 0.99로 사실상 같은 정보다.
  - 핵심 발견 : **배치가 바뀌어도 유지되는 신호는 ΔQ(V) 계열뿐이다.**

## Modeling

### 피처 엔지니어링 전략

피처는 초기 100 사이클 안에서 계산할 수 있고, **배치가 바뀌어도 수명과의 관계가 유지되는 것**을 기준으로 골랐다. Batch 1 안에서 상관이 높은 것만으로는 고르지 않았다.

| DAY 1 설계 | 피처 | EDA 근거 | DAY 2 결과 |
|---|---|---|---|
| 핵심 | log10(ΔQ(V) 분산) | 세 배치 모두에서 수명과 강한 상관 | 최종 모델의 유일한 피처 |
| 보조 후보 | 충전 시간, 평균 온도, 초기 용량 변화 | Batch 1 에서 상관이 있으나 배치 간에 불안정 | 더해도 교차검증 오차가 줄지 않아 기각 |
| 보조 후보 | 내부저항 변화 | 위와 같음 | Batch 2 의 6개 셀에 측정값이 없어 사용 불가 |
| 제외 | 충전 정책명, 용량의 절대 수준, ΔQ(V) 최솟값·평균 | 배치 간에 겹치지 않거나, 배치 차이가 그대로 들어가거나, 분산과 중복 | 용량의 절대 수준을 넣으면 교차검증은 6.87%로 좋아지나 Batch 2 가 44.8%로 나빠짐 |

입력 범위 이후의 값이 섞이지 않도록, 피처 함수는 초기 100 사이클로 잘라낸 데이터만 입력으로 받는다. 스케일링과 로그 변환은 모델 파이프라인 안에 두어 학습 데이터에서만 기준을 구한다.

### 모델 선택 및 근거

- 후보 모델 : 평균 예측(비교 기준), 단일 피처 선형 회귀, 보조 피처를 하나씩 더한 선형 회귀, Ridge, Elastic Net, Random Forest, Gradient Boosting
- 최종 모델 : **단일 피처 선형 회귀.** log10(수명) = a × log10(ΔQ(V) 분산) + b
- 선택 이유 :
  - 로그-로그에서 직선 관계가 확인됐다 (EDA 상관 -0.94).
  - 피처나 모델을 늘려도 교차검증 오차가 표준오차(0.4 ~ 0.6) 이상 줄지 않았다.
  - 학습 셀이 41개뿐이고 Batch 2 는 학습 범위 밖의 수명을 예측해야 한다. 직선을 연장할 수 있는 선형 모델이 맞다.

**평가 절차.** Batch 1 을 셀 단위로 Train 32개와 Hold-out 9개로 나눴다(수명 구간별 비율 유지). Train 안에서 5-fold 교차검증을 10회 반복해 후보를 비교했고, 모델 선택에는 이 점수만 썼다. 선택한 모델은 Batch 1 전체로 다시 학습해 Batch 2 와 3 에서 한 번 평가했다.

| 가설 | 결과 (교차검증 MAPE) | 판정 |
|---|---|---|
| ΔQ(V) 분산 하나로 수명을 예측할 수 있다 | 평균 예측 23.35% -> 9.28% | 채택 |
| 보조 피처를 더하면 성능이 오른다 | 9.26%, 9.62%, 11.03% | 기각 |
| 여러 피처를 쓰는 규제 선형·트리 모델이 더 낫다 | 9.10 ~ 10.54%. 가장 좋은 것도 표준오차 이내 | 기각 |
| 트리 계열은 학습 범위 밖 예측에 불리하다 | Batch 2 에서 28.9 ~ 32.7%, 선형은 26.2% | 채택 |

## 성능 결과

| 구분 | MAPE (%) | 비고 |
|---|---|---|
| Train (Batch 1 CV) | 9.28 | |
| Valid (Batch 1 Hold-out) | 8.87 | |
| Test (Batch 2) | 26.17 | |
| Gap (Train-Valid) | -0.41 | (+) : 과적합 의심 |
| Gap (Valid-Test) | 17.30 | (+) : 배치간 일반화 저하 의심 |
| Gap (Target-Test) | 17.07 | Target : 원논문 9.1% |
| Test (Batch 3) | 13.25 | |
| Gap (Batch2-Batch3) | -12.92 | Test 성능 간 비교 |
| Gap (Target-Test) | 4.15 | Batch 3 기준, 원논문 성능 비교 |

Gap 은 "뒤 단계 − 앞 단계"로 계산했다. 양수면 뒤 단계에서 성능이 나빠진 것이다.

- **Train - Valid (-0.41)** : 과적합이 없다. Hold-out 이 9개뿐이라 분할을 20번 바꿔 확인했고, CV 9.32 ± 0.69, Valid 9.28 ± 2.19로 같은 수준이다.
- **Valid - Test (+17.30)** : 배치 간 일반화가 크게 떨어진다. 셀마다 제각각 틀린 것이 아니라 Batch 2 전체를 일괄적으로 길게 예측했다 ([오류 분석](#오류-분석)).
- **Target - Test (+17.07)** : 원논문의 9.1%와는 평가 조건이 다르다. Batch 2 는 원논문에 없는 배치이고, 9.1%는 두 배치로 학습한 피처 9개짜리 모델의 값이다. 아래에서 조건을 맞춰 비교했다.

DAY 1 설계서에 적은 예상 위험이 그대로 나타났다. "Batch 2 는 학습 범위 밖을 예측해야 한다", "Batch 2 는 같은 ΔQ(V) 분산에서 수명이 더 짧은 쪽에 있다", "트리 계열은 Batch 2 에서 불리하다"는 세 가지가 모두 결과에서 확인됐다.

### 원논문 방법과의 비교

원논문의 수치와 직접 비교할 수 없으므로, **원논문의 방법을 이 데이터셋에 적용해 같은 조건에서 비교했다.** 원논문의 후보 피처 20개와 세 가지 모델 구성(elastic net)을 구현하고 Batch 1 로 학습했다. Variance 는 이 프로젝트의 최종 모델과 같은 구성이다.

| 모델 (선택된 피처 / 후보) | Batch 1 CV | Batch 2 | Batch 3 | 원논문이 보고한 값 (Batch 3 와 같은 배치) |
|---|---|---|---|---|
| Variance (1 / 1) : 최종 모델 | 9.28 | **26.17** | 13.25 | 11.4 |
| Discharge (8 / 13) | 7.59 | 32.79 | 9.14 | 8.6 |
| Full (11 / 20) | 9.80 | 34.25 | 9.11 | 10.7 |

- **Batch 3 에서는 원논문의 수치가 1 ~ 2%p 이내로 재현된다.** 구현과 전처리가 원논문과 크게 어긋나지 않는다는 근거다.
- **Batch 2 에서는 원논문의 다피처 모델이 최종 모델보다 6 ~ 8%p 나쁘다.** Batch 2 의 오차가 큰 것은 모델이 원논문보다 단순해서가 아니다.
- 피처를 늘리면 Batch 3 는 좋아지고 Batch 2 는 나빠진다. elastic net 이 고른 피처에 용량의 절대 수준이 들어 있는데, 이 값은 배치마다 수준이 다르다. 세 배치에서 모두 좋은 모델은 없었다.

원논문의 모델링 코드는 공개되어 있지 않아 세부 설정은 같지 않을 수 있다. Full 모델의 Batch 2 는 내부저항 측정값이 있는 33개 셀 기준이다.

### 추가 결과 : 단수명 셀 선별

원논문은 정확한 수명 값보다 빠른 판단이 필요한 용도(선별·등급 분류, 팩 설계)를 위해 분류 결과를 함께 제시한다. 같은 관점에서 "수명이 550 사이클 미만인 셀을 가려낼 수 있는가"를 확인했다. 학습 배치에 단수명 셀이 1개뿐이므로, **단수명 예시 없이 가려내는 문제**가 된다.

| 방법 | 입력 | Batch 2 Accuracy | Batch 2 단수명 검출률 | Batch 3 Accuracy |
|---|---|---|---|---|
| 원논문의 분류기 (로지스틱 회귀) | 5 사이클 | 0.231 | 0.000 | 0.975 |
| 회귀 모델의 예측 수명을 550으로 판정 | 100 사이클 | 0.538 | 0.400 | 0.975 |
| 예측 수명의 하한을 550으로 판정 | 100 사이클 | 0.949 | 0.933 | 0.975 |
| Zero-shot 분류기 | 100 사이클 | 0.974 | 0.967 | 0.975 |

(Batch 2 는 장수명 9개와 단수명 30개, Batch 3 는 장수명 39개와 단수명 1개다. 전부 장수명으로 판정하면 Batch 2 는 0.231, Batch 3 는 0.975가 나온다. Batch 3 의 단수명 셀 1개를 잡은 것은 예측 하한 방법뿐이고, 대신 장수명 셀 1개를 잘못 판정했다.)

- **분류기를 직접 학습하면 전부 장수명으로 판정한다.** 단수명을 배울 예시가 없기 때문이다.
- **회귀 모델은 순서를 완벽하게 맞힌다.** 예측 수명으로 장·단수명을 가르는 AUC 가 Batch 2 와 3 모두 1.00이다. 정확도가 0.538인 것은 예측이 일괄적으로 길어 판정 기준선이 어긋났기 때문이다.
- **기준선을 테스트 라벨 없이 옮기는 방법 두 가지가 통했다.**
  - 예측 하한 : Batch 1 의 leave-one-out 오차로 예측의 90% 하한을 만들어 판정한다 (conformal prediction). 단수명 셀 30개 중 28개를 잡았다.
  - Zero-shot 분류기 : 수명과 피처의 관계에서 단수명 셀의 피처를 합성해 이진 분류기를 학습한다 (생성형 zero-shot). 피처와 판정 기준은 Batch 1 에서 수명이 짧은 셀 일부를 숨겨 두고 그 셀을 가려내는지로 골랐다. 30개 중 29개를 잡았다.
- **대가는 오경보다.** 두 방법 모두 Batch 1 내부에서 장수명 셀의 11 ~ 13%를 단수명으로 판정한다.

이 결과를 읽을 때 알아야 할 조건이 있다.

- **테스트 결과를 본 뒤에 추가한 실험이다.** 위 성능 표와 같은 무게로 읽으면 안 된다. 하한의 수준 90%도 그 뒤에 정했고, 80%였다면 Batch 2 정확도는 0.641이다.
- **Zero-shot 분류기의 0.974는 기본 분할의 값이다.** 분할을 10번 바꾸면 선택되는 피처가 달라져 평균 0.884(0.641 ~ 0.974)다. 어느 경우에도 0.538보다는 높다.
- **입력이 100 사이클이다.** 5 사이클로 줄이면 이 프로젝트의 방법도 0.231이다. 원논문의 "제조 직후 5 사이클 선별"과는 조건이 다르므로 원논문의 95.1%와 비교하지 않는다.
- One-class 이상 탐지(Mahalanobis, Isolation Forest, One-Class SVM, LOF)도 시도했으나, 수명이 아니라 배치 차이를 이상으로 잡아 실패했다.

방법과 전체 수치는 [모델 개발 기록](docs/DAY2_MODELING.md) 9 ~ 10절에 있다.

## 오류 분석

**모델이 가장 크게 틀린 셀의 공통점.**

- **Batch 2 는 39개 중 38개를 실제보다 길게 예측했다.** 오차가 가장 큰 셀은 449 -> 730(62.7%), 393 -> 632(60.9%)다. 특정 셀이 아니라 배치 전체가 같은 방향으로 틀렸다.
- **수명이 1,800 이상인 셀은 짧게 예측했다.** Batch 1 Hold-out 2237 -> 1629, Batch 3 1935 -> 1225. 수명이 매우 긴 셀은 초기 100 사이클의 ΔQ(V) 가 측정 노이즈 수준이어서 구분되지 않는다.

**원인 가설과 검증.** 테스트 결과를 본 뒤의 분석이므로 성능 표에는 반영하지 않았다.

| 가설 | 결과 | 판정 |
|---|---|---|
| Batch 2 의 오차는 배치 전체의 일정한 편향이다 | 예측 / 실제가 Batch 2 1.23 ~ 1.26배, Batch 3 1.05배. 편향을 제거하면 MAPE 9.5 ~ 14.1% | 채택 |
| ΔQ(V) 의 기준 사이클을 바꾸면 편향이 줄어든다 | cycle 3 ~ 40 어느 것을 써도 1.21 ~ 1.25배 | 기각 |
| 초기 용량 상승폭을 더하면 배치 차이가 설명된다 | Batch 2 는 21.6%로 좋아지나 Batch 3 가 21.9%로 나빠짐 | 기각 |
| 초기 용량의 절대 수준을 더하면 성능이 오른다 | Batch 1 CV 는 6.87%로 가장 좋으나 Batch 2 가 44.8%로 나빠짐 | 기각 |

Batch 2 는 같은 ΔQ(V) 분산에서 수명이 약 20% 짧다. 아래 그림에서 Batch 2 의 점들이 Batch 1 의 회귀선 아래에 평행하게 놓여 있다. 학습 배치가 하나뿐이면 이런 배치 간 차이를 데이터에서 배울 수 없다.

![Core feature fit](results/figures/core_feature_fit.png)

**개선 방향.**

- **기준선 보정.** 새 배치에서 수명이 확인된 셀 몇 개로 예측의 절편만 보정하면 Batch 2 의 MAPE 가 1개로 15.0%, 3개로 12.5%, 5개로 11.8%가 된다.
- **여러 배치로 학습.** 조건이 다른 배치를 함께 학습해야 배치 간 차이를 모델이 배울 수 있다. 원논문은 두 배치를 섞어 학습했다.
- **장수 셀.** 관측 기간을 100 사이클보다 늘리면 변화가 작은 셀도 구분할 수 있다.

## ESS 도메인 해석

**어떤 의사결정에 활용할 수 있는가.**

- **교체 계획.** 같은 조건에서 수집한 데이터로 학습했다면 수명을 약 9% 오차로 예측한다. 예기치 못한 설비 중단과 불필요한 조기 교체를 줄이는 근거가 된다.
- **셀 선별과 팩 구성.** 초기 100 사이클만 돌려 보면 어느 셀이 먼저 수명을 다할지 순서를 알 수 있다. 수명이 비슷한 셀끼리 묶거나, 수명이 짧을 셀을 출하 전 샘플 검사에서 걸러낼 수 있다.

**한계와 실 배포에 필요한 것.**

- **조건이 바뀌면 수명 수준이 어긋난다.** 시험 조건이 다른 배치에서 예측이 일괄적으로 20% 이상 벗어났다. 실제 ESS 는 온도, 충·방전 패턴, 제조 로트가 실험실보다 다양하다. 조건마다 수명이 확인된 셀 몇 개로 기준선을 보정하는 절차가 필요하다.
- **초기 100 사이클의 관측이 필요하다.** 5 사이클로는 신호가 없어 제조 직후의 즉시 선별에는 쓸 수 없다.
- **셀 단위의 결과다.** 모듈이나 랙의 수명은 셀 간 불균형과 열 관리의 영향을 받으므로 별도의 검증이 필요하다.
- **고속 충전 실험 데이터다.** 실제 운전 조건에서 같은 관계가 성립하는지는 확인되지 않았다.
