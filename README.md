# ESS 배터리 수명 예측

배터리 셀의 **초기 100 사이클 측정값만으로** 그 셀의 총수명(cycle life)을 예측한다. ESS 에서 배터리 교체 비용은 설비 투자의 30 ~ 40%를 차지한다. 수명을 미리 알면 교체 시점을 계획하고, 수명이 짧을 셀을 일찍 가려낼 수 있다.

## 프로젝트 개요

- 데이터셋 : MIT-Stanford Battery Dataset. Severson et al. (2019) 의 데이터이며, 이하 이 논문을 "원논문"이라 한다.
- 학습 데이터 : Batch 1 (2017-05-12), 41개 셀
- 평가 데이터 : Batch 2 (2018-02-20), 39개 셀. 추가 평가로 Batch 3 (2018-04-12), 40개 셀
- 태스크 : **Regression** (Cycle Life 예측)

**태스크 선택 근거.**

- 교체 계획은 시점을 정하는 일이다. 언제 교체할지, 그에 맞춰 예산과 교체 물량을 언제 확보할지를 정하려면 남은 수명이 사이클 수로 나와야 한다.
- Classification 은 초기 5 사이클만 보고 장수명 / 단수명(550 사이클 기준)을 가르는 문제다. 원논문은 이 문제를 제조 직후의 셀을 수명 등급에 따라 선별(sorting / grading)하는 것처럼 빠른 판단이 필요한 용도로 제시한다.
- 이 프로젝트는 ESS 의 교체 계획에 초점을 두어 수명 값을 예측하는 Regression 으로 진행했다.

두 문제는 입력(5 사이클 / 100 사이클)과 쓰임(선별 / 교체 계획)이 다르다. 그래서 Regression 의 예측값을 기준선으로 나눠 장·단수명을 가르는 것은 본래 Classification 의 목적(5 사이클 시점의 즉시 선별)에 부합하지 않는다. 다만 100 사이클도 용량이 거의 줄지 않은 초기 구간이므로, 운영 초기에 일찍 수명을 다할 셀을 미리 표시해 우선 점검하거나 교체 순서를 정하는 용도로는 쓸 수 있다고 판단해 추가로 실험했다.

## EDA

전체 내용과 그래프는 [DAY 1 보고서](docs/DAY-1.pdf)에 있다. 여기에는 모델 설계로 이어진 발견만 적는다.

- Cycle Life 분포
  - 수명 중앙값은 Batch 1 842, Batch 2 472, Batch 3 964.5다. 단수명(<500) 비율은 0% / 72% / 0%, 장수명(>1,000) 비율은 24% / 8% / 48%다.
  - 핵심 발견 : **학습 배치와 테스트 배치의 수명 분포가 거의 겹치지 않는다.** Batch 2 셀의 77%가 Batch 1 의 최솟값(534)보다 짧다.

- 열화 곡선 분석
  - 용량은 오랫동안 평탄하다가 말기에 급락한다. Knee point 는 세 배치 모두 수명의 82 ~ 87% 지점에서 나타난다.
  - 장수명 셀과 단수명 셀은 급락하는 속도가 비슷하고(knee 에서 EOL 까지 65 ~ 163 사이클), 급락이 시작되는 시점이 다르다.
  - 핵심 발견 : **수명은 knee 의 시작 시점으로 결정되는데(상관 0.986), 초기 100 사이클의 용량 곡선에는 그 신호가 없다.**

- ΔQ(V) 곡선 분석
  - ΔQ(V) = Q100(V) − Q10(V). cycle 100 과 cycle 10 의 방전 용량-전압 곡선의 차이로, 2.9 ~ 3.0 V 부근에서 가장 깊어지는 곡선이다.
  - 단수명 셀은 곡선이 깊게 내려가고(최솟값 중앙값 -0.056 Ah), 장수명 셀은 0 근처에 머문다(-0.022 Ah).
  - 핵심 발견 : **log(ΔQ 분산)과 log(수명)의 상관계수가 Batch 1 -0.94, Batch 2 -0.92, Batch 3 -0.80이다.**

- 충전 속도(C-rate)와 수명의 관계
  - Batch 1 은 충전이 빠를수록 수명이 짧다. 가장 느린 프로토콜의 평균 수명이 2083, 가장 빠른 프로토콜이 546이다.
  - Batch 2 와 3 은 모든 프로토콜의 충전 시간이 약 10분으로 같은데, 수명은 392 ~ 1935로 크게 다르다.
  - 핵심 발견 : **충전 조건은 한 배치 안에서만 수명을 설명한다.** 같은 프로토콜(`6C(60%)-3C`)의 수명이 Batch 1 에서 731, 757이고 Batch 2 에서 392, 408이다.

- 상관관계
  - 충전 시간과 수명의 상관은 배치마다 부호가 바뀐다 (0.81 / -0.94 / 0.55). 온도와 내부저항도 마찬가지다.
  - 핵심 발견 : **배치가 바뀌어도 유지되는 신호는 ΔQ(V) 계열뿐이다.**

## Modeling

### 피처 엔지니어링 전략

초기 100 사이클 안에서 계산할 수 있고, **배치가 바뀌어도 수명과의 관계가 유지되는 피처**를 골랐다. Batch 1 안에서 상관이 높다는 것만으로는 고르지 않았다.

| DAY 1 설계 | 피처                                 | EDA 근거                                            | DAY 2 결과                                                                      |
| ---------- | ------------------------------------ | --------------------------------------------------- | ------------------------------------------------------------------------------- |
| 핵심       | log10(ΔQ(V) 분산)                    | 세 배치 모두에서 수명과 강한 상관                   | 최종 모델의 유일한 피처                                                         |
| 보조 후보  | 충전 시간, 평균 온도, 초기 용량 변화 | Batch 1 에서만 상관, 배치 간에 불안정               | 더해도 교차검증 오차가 표준오차 이상 줄지 않아 기각 (9.26 ~ 11.03% vs 9.28%)    |
| 보조 후보  | 내부저항 변화                        | 위와 같음                                           | Batch 2 의 6개 셀에 측정값이 없어 사용 불가                                     |
| 제외       | 충전 정책명, 용량의 절대 수준        | 배치마다 값의 수준이 달라 배치 차이가 그대로 들어감 | 용량의 절대 수준을 넣으면 교차검증은 6.87%로 좋아지나 Batch 2 가 44.8%로 나빠짐 |

피처 함수는 초기 100 사이클로 잘라낸 데이터만 입력으로 받는다. 스케일링과 로그 변환은 모델 파이프라인 안에서 학습 데이터로만 기준을 구한다.

### 모델 선택 및 근거

- 후보 모델 : 단일 피처 선형 회귀, 보조 피처를 더한 선형 회귀, Ridge, Elastic Net, Random Forest, Gradient Boosting
- 최종 모델 : **단일 피처 선형 회귀.** log10(수명) = a × log10(ΔQ(V) 분산) + b
- 선택 이유 :
  - 로그-로그에서 직선 관계가 확인됐다 (EDA 상관 -0.94). 평균만 예측하면 교차검증 MAPE 가 23.35%이고 이 모델은 9.28%다.
  - 피처나 모델을 늘려도 나아지지 않았다. 다른 후보는 9.10 ~ 11.03%로, 가장 좋은 것도 표준오차(0.4 ~ 0.6) 이내다.
  - Batch 2 는 학습 범위 밖의 수명을 예측해야 하므로 직선을 연장할 수 있는 선형 모델이 맞다. 실제로 Batch 2 에서 트리 계열은 28.9 ~ 32.7%, 선형은 26.2%다.

**데이터 분할.** Batch 1 을 셀 단위로 Train 32개와 Hold-out 9개로 나눴다 (수명 구간별 비율 유지). Train 안에서 5-fold 교차검증을 10회 반복해 후보를 비교했고, 모델 선택에는 이 점수만 썼다. 같은 충전 프로토콜의 셀이 학습과 검증에 나뉘어 생기는 누수는 프로토콜 단위로 묶은 교차검증으로 확인했다 (9.45%로 차이 없음). 선택한 모델은 Batch 1 전체로 다시 학습해 Batch 2 와 3 에서 한 번 평가했다.

## 성능 결과

**비교 기준.** 목표값(Target)은 같은 데이터셋으로 같은 문제를 푼 원논문(Severson et al., 2019, _Data-driven prediction of battery cycle life before capacity degradation_)의 회귀 MAPE 9.1%다.

- 이 값과는 직접 비교할 수 없다. 원논문은 두 배치(2017-05-12, 2017-06-30)의 셀을 섞어 학습과 1차 테스트로 나눴는데, 그중 2017-06-30 배치가 이 데이터셋에 없다. 이 프로젝트의 Batch 2 는 원논문이 쓰지 않은 배치다 ([data/README.md](data/README.md)).
- 그래서 원논문이 제시한 모델을 직접 구현해, 이 프로젝트와 같은 조건(Batch 1 학습, Batch 2 · 3 평가)에서 어떤 결과가 나오는지 추가 실험으로 확인했다. 결과는 성능 표 다음에 있다.

| 구분                     |                     | MAPE (%) | 비고                           |
| ------------------------ | ------------------- | -------- | ------------------------------ |
| Train (Batch 1 CV)       |                     | 9.28     |                                |
| Valid (Batch 1 Hold-out) |                     | 8.87     |                                |
| Test (Batch 2)           |                     | 26.17    |                                |
|                          | Gap (Train-Valid)   | -0.41    | (+) : 과적합 의심              |
|                          | Gap (Valid-Test)    | 17.30    | (+) : 배치간 일반화 저하 의심  |
|                          | Gap (Target-Test)   | 17.07    | Target : 원논문 9.1%           |
| Test (Batch 3)           |                     | 13.25    |                                |
|                          | Gap (Batch2-Batch3) | -12.92   | Test 성능 간 비교              |
|                          | Gap (Target-Test)   | 4.15     | Batch 3 기준, 원논문 성능 비교 |

Gap 은 "뒤 단계 − 앞 단계"로 계산했다. 양수면 뒤 단계에서 성능이 나빠진 것이다.

- **Train - Valid (-0.41)** : 과적합이 없다. 분할을 20번 바꿔도 CV 9.32 ± 0.69, Valid 9.28 ± 2.19로 같은 수준이다.
- **Valid - Test (+17.30)** : 배치 간 일반화가 크게 떨어진다. 셀마다 제각각 틀린 것이 아니라 Batch 2 전체를 일괄적으로 길게 예측했다 ([오류 분석](#오류-분석)).
- **Batch 2 - Batch 3 (-12.92)** : Batch 3 가 더 잘 맞는다. 예측 편향이 Batch 2 는 1.25배이고 Batch 3 는 1.05배다. 피처가 특정 배치에 과적합된 것이 아니라 Batch 2 의 수명 수준 자체가 다르다.
- **Target - Test (+17.07, Batch 3 기준 +4.15)** : 목표값에 미치지 못한다. 다만 9.1%는 두 배치로 학습한 피처 9개짜리 모델의 값이어서 평가 조건이 다르다. 조건을 맞춘 비교는 아래 표다.

**원논문의 방법을 같은 데이터에 적용한 결과.** 원논문의 후보 피처 20개와 세 가지 모델 구성(elastic net)을 구현해 Batch 1 로 학습했다. Variance 가 이 프로젝트의 최종 모델과 같은 구성이다.

| 모델 (선택된 피처 / 후보)    | Batch 1 CV | Batch 2   | Batch 3 | 원논문이 Batch 3 와 같은 배치에서 보고한 값 |
| ---------------------------- | ---------- | --------- | ------- | ------------------------------------------- |
| Variance (1 / 1) : 최종 모델 | 9.28       | **26.17** | 13.25   | 11.4                                        |
| Discharge (8 / 13)           | 7.59       | 32.79     | 9.14    | 8.6                                         |
| Full (11 / 20)               | 9.80       | 34.25     | 9.11    | 10.7                                        |

Full 의 Batch 2 값은 내부저항 측정값이 있는 33개 셀 기준이다. 내부저항을 빼고 39개 셀로 평가하면 35.31%다.

- Batch 3 에서는 원논문의 수치가 1 ~ 2%p 이내로 재현된다. 구현과 전처리가 원논문과 크게 어긋나지 않는다.
- Batch 2 에서는 원논문의 다피처 모델이 최종 모델보다 6 ~ 8%p 나쁘다.

### 추가 결과 : 단수명 셀 선별

[프로젝트 개요](#프로젝트-개요)에서 밝힌 것처럼, 여기서의 선별은 원논문의 Classification(5 사이클 시점의 즉시 선별)과 다른 문제다. 100 사이클을 운영한 뒤에 회귀 모델의 예측 수명을 이용해, 일찍 수명을 다할 셀(550 사이클 미만)을 미리 표시할 수 있는지 확인했다. 원논문의 분류기는 5 사이클 입력으로는 판정이 되지 않는다는 것을 보이기 위한 참고 행이다.

| 방법 | 입력 | Batch 2 Accuracy | Batch 2 단수명 검출률 |
| --- | --- | --- | --- |
| (참고) 원논문의 분류기 | 5 사이클 | 0.231 | 0.000 |
| ① 예측 수명이 550 미만이면 단수명 | 100 사이클 | 0.538 | 0.400 |
| ② 예측 수명의 90% 하한이 550 미만이면 단수명 | 100 사이클 | 0.949 | 0.933 |
| ③ 단수명 셀의 피처를 합성해 학습한 zero-shot 분류기 | 100 사이클 | 0.974 | 0.967 |

- **① 예측 수명 기준.** 회귀 모델은 셀의 수명 순서를 완벽하게 맞힌다 (AUC 1.00). 그런데 Batch 2 의 예측이 일괄적으로 길어서, 실제 단수명 셀의 60%가 550 위로 예측돼 놓친다.
- **② 90% 하한 기준.** 예측 수명에는 오차가 있으므로, 600으로 예측된 셀의 실제 수명은 500일 수도 있다. 선별에서는 단수명 셀을 놓치는 쪽이 장수명 셀을 한 번 더 점검하는 쪽보다 손해가 크다. 그래서 "실제 수명이 이 값보다는 길다고 90% 확신할 수 있는 값"(하한)을 구해, 그 하한이 550을 넘는 셀만 장수명으로 판정한다. 하한은 예측 수명을 1.19로 나눈 값이고, 1.19는 Batch 1 에서 모델이 실제보다 길게 예측한 정도의 90% 분위수다 (conformal prediction). 테스트 배치의 정답은 쓰지 않는다.
- **③ zero-shot 분류기.** Batch 1 에서 배운 "수명 -> 피처" 관계로 단수명 셀의 피처를 합성해, 실제 단수명 셀 없이 분류기를 학습한다.

**읽을 때의 주의.** 테스트 결과를 본 뒤에 추가한 실험이므로 위 성능 표와 같은 무게로 읽으면 안 된다.

- ② 는 대가가 있다. Batch 1 에서는 장수명 셀의 13%를 단수명으로 잘못 표시한다. 수준을 80%로 잡았다면 Batch 2 의 Accuracy 는 0.641이다.
- ③ 은 피처 선택이 불안정하다. Batch 1 의 분할을 10번 바꾸면 Batch 2 의 Accuracy 가 평균 0.884(0.641 ~ 0.974)다.
- 입력이 100 사이클이므로 원논문의 95.1%(5 사이클)와는 비교하지 않는다.

방법과 전체 수치는 [results/README.md](results/README.md)에 있다.

## 오류 분석

**모델이 가장 크게 틀린 셀의 공통점.**

- Batch 2 는 39개 중 38개를 실제보다 길게 예측했다 (예 : 449 -> 730, 393 -> 632). 특정 셀이 아니라 배치 전체가 같은 방향으로 틀렸다.
- 수명이 1,800 이상인 셀은 짧게 예측했다 (2237 -> 1629, 1935 -> 1225). 수명이 매우 긴 셀은 초기 100 사이클의 ΔQ(V) 가 측정 노이즈 수준이어서 구분되지 않는다.

**원인 가설과 검증.** 테스트 결과를 본 뒤의 분석이므로 성능 표에는 반영하지 않았다.

| 가설                                          | 결과                                                                                  | 판정 |
| --------------------------------------------- | ------------------------------------------------------------------------------------- | ---- |
| Batch 2 의 오차는 배치 전체의 일정한 편향이다 | 예측 / 실제가 Batch 2 1.23 ~ 1.26배, Batch 3 1.05배. 편향을 제거하면 MAPE 9.5 ~ 14.1% | 채택 |
| ΔQ(V) 의 기준 사이클을 바꾸면 편향이 줄어든다 | cycle 3 ~ 40 어느 것을 써도 1.21 ~ 1.25배                                             | 기각 |

Batch 2 는 같은 ΔQ(V) 분산에서 수명이 약 20% 짧다. 아래 그림에서 Batch 2 의 점들이 Batch 1 의 회귀선 아래에 평행하게 놓여 있다. 학습 배치가 하나뿐이면 이런 배치 간 차이를 데이터에서 배울 수 없다.

**개선 방향.**

- 기준선 보정 : 새 배치에서 수명이 확인된 셀 몇 개로 절편만 보정하면 Batch 2 의 MAPE 가 1개로 15.0%, 3개로 12.5%, 5개로 11.8%가 된다.
- 여러 배치로 학습 : 조건이 다른 배치를 함께 학습해야 배치 간 차이를 모델이 배울 수 있다. 원논문은 두 배치를 섞어 학습했다.

## ESS 도메인 해석

**어떤 의사결정에 활용할 수 있는가.**

- 교체 계획 : 같은 조건에서 수집한 데이터로 학습했다면 수명을 약 9% 오차로 예측한다. 예기치 못한 설비 중단과 불필요한 조기 교체를 줄이는 근거가 된다.
- 셀 선별과 팩 구성 : 초기 100 사이클만 돌려 보면 어느 셀이 먼저 수명을 다할지 순서를 알 수 있다. 수명이 비슷한 셀끼리 묶거나 수명이 짧을 셀을 걸러낼 수 있다.

**한계와 실 배포에 필요한 것.**

- 조건이 바뀌면 수명 수준이 어긋난다. 시험 조건이 다른 배치에서 예측이 일괄적으로 20% 이상 벗어났다. 실제 ESS 는 온도, 충·방전 패턴, 제조 로트가 더 다양하므로, 조건마다 수명이 확인된 셀 몇 개로 기준선을 보정하는 절차가 필요하다.
- 초기 100 사이클의 관측이 필요하다. 5 사이클로는 신호가 없어 제조 직후의 즉시 선별에는 쓸 수 없다.
- 셀 단위의 고속 충전 실험 결과다. 모듈·랙 단위의 수명과 실제 운전 조건에서는 별도의 검증이 필요하다.
